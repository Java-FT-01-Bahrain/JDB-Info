## Introduction

For this homework, imagine that you're building a new feature for Instagram (any feature! large or small! your choice). You should write user stories and acceptance criteria for the new feature.

The stories and acceptance criteria will help guide your work on the project and help you articulate *why* you made the technical choices you did.

---

## Exercise

### Set Up

You will need a Pivotal Tracker account for this exercise. 

Don't have an account yet? [Click here](https://www.pivotaltracker.com/) to create a free account if you don't have one already. Then, create a new project for this course.

### Requirements

- Write at least five user stories for the application.
- All user stories must include 2–3 acceptance criteria.
- Stories and acceptance criteria should follow the format we discussed in class.

#### Pivotal Tracker Set Up

In your course project, create a new epic for this homework assignment. Add your stories and acceptance criteria into the epic. Be sure to point the story, include any blockers, and add a detailed description. (Bonus: Add the tasks that will need to be completed for the story.)

### Deliverable

A link to your Pivotal Tracker account with the stories.
